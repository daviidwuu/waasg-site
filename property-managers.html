How I work with Buildium and AppFolio.

Useful workflows can start from the reports and exports you already have. Where your plan includes API access or a built-in integration, I can connect to it directly. You don't need to change software.

Which plan fits.

Growth (US$1,800/month) for owner-lead growth. Automation partner (US$3,500/month) when you want the admin automations too. Compare plans.

Do I need API access to my property management software?

No. Many useful automations run on scheduled reports, exports and email. API access, where your plan includes it, makes things faster and more real-time.

Will anything be sent to owners or residents automatically?

Only if you decide it should be. By default, AI drafts and your team approves.
